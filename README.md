# Proyecto Final Integrador 2

Este repositorio contiene el desarrollo del **Proyecto Final Integrador 2**, una iniciativa con fines educativos.

## Estructura del Proyecto

- `src/`: Código fuente de la aplicación.
- `web/`: Archivos relacionados con la interfaz web.
- `nbproject/`: Configuraciones del entorno NetBeans (si aplica).
- `db_hotel.sql`: Script de base de datos para el sistema.
- `build.xml`: Archivo de construcción del proyecto.

## Objetivo

El propósito de este proyecto es aplicar los conocimientos adquiridos durante el curso, integrando diferentes tecnologías y metodologías en un solo desarrollo funcional.

## Tecnologías Utilizadas

- Java (JSP/Servlets)
- MySQL
- NetBeans IDE
- HTML/CSS/JavaScript (si aplica)

## Autor

Desarrollado como parte de una actividad académica.
